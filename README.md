## 常见问题

### 德国服务器放在法兰克福，访问中国大陆一定很快吗？

不一定。机房地理位置只是其中一个因素，运营商、回程线路、跨网互联和用户所在地都会影响结果。近期德国 9929 VPS 的两次测试已经出现了明显的运营商差异，因此“法兰克福 = 固定多少毫秒”这种说法并不可靠。

### 德国 9929 VPS 是住宅 IP 吗？

从目前搜到的第三方检测结果看，测试样本的确是德国原生 IP，但被识别为 **IDC 机房 IP**，不是住宅 IP。

### 德国双 ISP VDS 和 9929 VPS 最大区别是什么？

最直观的区别就是产品定位。9929 VPS 重点是**德国原生 IP + 三网 9929 优化网络**；双 ISP VDS 重点是**德国原生住宅 IP + 双 ISP 属性**，但官方明确说明它不是大陆优化网络。

### “不限流量”是不是可以跑满 1Gbps？

不是。当前德国 9929 VPS 的不限流量 Lite/Pro 分别只有 50Mbps 和 100Mbps；德国住宅 VDS 的不限流量 Lite/Pro 分别是 100Mbps 和 200Mbps。不限的是流量额度，不是端口速率。

### 支持 Windows 吗？

LisaHost 当前德国 9929 VPS 页面和德国双 ISP 住宅 VDS 页面都公开注明支持 Windows。

### 第一次租德国服务器，应该直接买年付吗？

先看产品类型。普通德国 9929 VPS 有月付档，而且官网提供 48 小时不满意退款；住宅 VDS 属于特殊产品，退款只退网站余额。对于尚未验证 IP 属性和线路的业务，购买前把售后规则看清楚，比单纯追求年付价格低更重要。
